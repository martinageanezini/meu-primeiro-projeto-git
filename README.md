# meu-primeiro-projeto-git
Meu primeiro projeto versionado no GitHub.


NOME: Martina De Conto Geanezini.


PROJETO: Calculadora de Média de 5 notas.


OBJETIVO: Calcular a média das cinco notas digitadas e apresentar o resultado de Aprovação ou Reprovação.


TECNOLOGIAS UTILIZADAS: VSCODE e Python.


COMO EXECUTAR: Este é um script simples em Python que calcula a média de cinco notas de um aluno e exibe se ele foi aprovado (média maior ou igual a 7) ou reprovado.


Para rodar este script, você só precisa ter o Python 3 instalado em seu computador.
 - Se não tiver o Python instalado, baixe e instale a versão oficial em python.org.

Passo a Passo:
  1. Salvar e baixar o arquivo no seu computador.
  2. Abrir o terminal no VSCODE ou no PowerShell (certifique-se de que tenha ou o PowerShell ou o VSCODE instalados na sua máquina).
  3. Execute o Programa.

Ao executar o programa deverá solicitar 5 notas e ao final apresentar a média e o resultado de Aprovado ou Reprovado.
